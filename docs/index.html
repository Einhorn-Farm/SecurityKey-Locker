How it works

A Windows service runs in Session 0 and can't lock your desktop directly, so YubiKey Locker does it in two steps:

  1. It subscribes to WMI PnP device-removal events, filtered to your key's USB vendor id (1050 = Yubico).
  2. On removal it resolves the console session's user token (WTSQueryUserToken) and launches LockWorkStation in that session via CreateProcessAsUser.

Duplicate events from a single unplug are de-bounced, and the lock is fail-safe by design. Full details are in the README.
